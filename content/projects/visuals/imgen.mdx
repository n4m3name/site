Headless AI image generation driven from a local CLI against a RunPod 4090. Aesthetic anchored on Cunningham, Giger, Autechre video work, and shitty-camera capture media.

Generation runs in stages: hand-jotted notes → <RefPreview><RefContent /></RefPreview> → <RefPreview label="prompts.md"><PromptsContent /></RefPreview> → images. Only the first stage is hand-written; everything below it is LLM output the previous stage seeded.

## Pipeline

**1. Notes → `ref.md`.** A short hand-written list of cultural anchors and keywords (Cunningham, Giger, Autechre *Second Bad Vibel*, bad camera, messy server rooms, biotech, breakcore pacing) gets expanded by an LLM into `ref.md`: a structured spec covering direct references, motifs, materials, capture-medium rules, color and light constraints, negative-prompt cues.

**2. `ref.md` → `prompts.md`.** An LLM expands the spec into a numbered batch of prompts. Rules baked in:
- No explicit color words; LoRAs and negatives govern palette
- Value / contrast / intensity language only (dim, hard, harsh, blown highlights, crushed shadows)
- `Photograph of` prefix, medium-wide framing, surveillance / found-footage framing
- Categories: scenes, characters, vessels, objects, specimens, textures

`imgen N` looks up prompt N and feeds it to ComfyUI.

**3. `prompts.md` → images.** SDXL + a LoRA stack renders each prompt. LoRA stack swaps per "combo" file in `app/workflows/combos/`: e.g. `A_xeno_high.json` = Xenomorph-15 @ 1.0; `N_xeno+alien+pol.json` = Xenomorph-15 + alienzkin-sdxl + Polaroidv2. Same prompt × multiple combos is the variant sweep below.

## Setup

- ComfyUI on a RunPod 4090, driven headless from a local CLI via HTTPS proxy; no SSH tunnel for generation
- Model weights live on a 50GB Network Volume that survives pod stop and terminate, so neither costs GPU time and `imgen-pod recreate` rebuilds the pod against the same volume non-destructively
- Pod auto-starts on `imgen N`, runs, auto-stops; on-pod watchdog also self-stops on idle so a local crash doesn't burn GPU
- SDXL base 1.0 + refiner 1.0, 1024×1024, 25 steps, `dpmpp_2m` / karras, CFG 8
- Long aesthetic-negative prompt (anti-glossy, anti-warm-tone, anti-portrait, anti-magenta, anti-render)
