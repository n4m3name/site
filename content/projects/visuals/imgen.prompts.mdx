# Prompts  

**Image** prompts for SDXL base + xeno LoRA stack. Patterns refined from `outputs/keepers/`. Drawn from `ref.md`.  

Run images:  
```bash
imgen s2                                             # default workflow
imgen s2 --workflow workflows/combos/<combo>.json    # specific combo
imgen s2 --seed 42 --keep                            # specific seed
imgen "literal text"                                 # ad hoc
```
Images land in `outputs/images/<category>/<id>-s<seed>.png`.  

**Rules:**  
- **No specific color words anywhere** (no red / magenta / green / blue / pink / yellow / orange). The LoRAs and negatives govern palette; explicit color names in prompt bias toward saturated single-color renders.  
- Use **value / contrast / intensity** language instead: dim, hard, harsh, low-key, single-source, directional, blown highlights, deep crushed shadows, pure black surround.  
- Medium-wide framing, subject in tech-cluttered space, surveillance / found-footage framing, "Photograph of" prefix, no direct references.
